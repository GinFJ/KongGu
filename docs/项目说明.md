# 空谷项目说明

> 本文档与 `README.md`（产品主页）和 `PROJECT_CHRONICLE.md`（项目沿革）配合使用：README 面向首次接触者，项目史记录 V0.1 至 0.3.0 的完整沿革，本文档固定记录定位、流程和范围边界。

## 一、项目定位

空谷是青禾计划孵化的课表协作产品。“空”指空课表，“谷”承接青禾从禾苗成长为谷物的意象。

项目不是普通个人课表工具，而是面向学生组织负责人和协作团队的多人课表汇总与排班辅助产品。

## 二、解决的问题

学生组织安排值班、活动、会议、培训和志愿服务时，通常需要人工收集多名成员的中方、英方课表，再逐人、逐周、逐节核对共同空闲时间。

这一过程存在：

- 文件来源分散；
- 课表版式不统一；
- 中方、英方课表需要配对；
- 身份、周次、星期和节次容易误判；
- 人工核对耗时；
- 错误不易追溯；
- 课表包含个人信息。

空谷将源材料转化为可预览、可复核、可追溯、可导出的集体空闲结果。

## 三、处理流程

```text
源文件
→ 输入预检
→ 文本层提取
→ 必要时本地 OCR
→ 版式识别
→ 课程块结构化
→ 成员占用合并
→ 空闲计算
→ 质量判断
→ 人工复核
→ 正式导出
```

## 四、产品原则

- 本地处理；
- 离线交付；
- 错误可见；
- 来源可追溯；
- 修正有记录；
- 质量门禁优先；
- 可信结果优先于功能数量。

## 五、核心输出

正式输出应根据实际需求提供：

- 排班汇总视图；
- 可筛选空课明细；
- 成员和课表完整性检查；
- 课程占用及来源；
- 解析问题和处理状态；
- 人工修正历史；
- 文件处理记录；
- 使用说明。

## 六、范围边界

默认不建设云同步、成员数据库、报名、考勤和与课表排班闭环无关的复杂组织管理功能。新增范围必须由用户明确确认。
