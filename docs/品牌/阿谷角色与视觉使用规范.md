# 阿谷角色与视觉使用规范

> 规范版本：1.1
> 生效日期：2026-08-11  
> 适用范围：空谷桌面端、README、项目文档、汇报展示和宣传材料

## 一、角色身份

阿谷是空谷的非人虚拟形象，是一只向着阳光生长的谷物精灵。

空谷是青禾计划孵化的课表协作产品。“空”指空课表，“谷”承接青禾从禾苗生长为谷物的意象。阿谷的核心表达是：

> 青心如禾，向阳而生。

“谷”不得解释为山谷。阿谷的形象和文案不得使用山峰、峡谷、溪流等地形意象替代谷物含义。

## 二、固定识别特征

以下三项共同构成阿谷的核心识别，不得在衍生设计中删除或替换：

1. **双叶冠**：头顶一左一右两片舒展的青禾叶，表达面向阳光的生长状态。
2. **透明青心种仁**：腹部透明种仁包裹两片嫩叶，对应“青心如禾”。
3. **圆润谷粒身体**：非人、短圆、富有弹性的谷物精灵轮廓。

阿谷的常规神态应当明亮、俏皮、主动。它代表青年在参与、协作和实践中不断生长，不以“隐私守护者”作为主要人格定位。

## 三、性格与语言

### 3.1 性格关键词

- 俏皮活泼；
- 热情友好；
- 乐于协作；
- 有行动力；
- 向阳生长。

### 3.2 推荐表达

- “青心如禾，向阳而生。”
- “把大家的课表放在一起，看看什么时候都有空。”
- “先核对清楚，再生成空课表。”

### 3.3 不推荐表达

- 不把阿谷写成无所不能的人工智能。
- 不把角色重点收窄为隐私、安全或数据守护。
- 不用幼儿化叠词替代正常的操作提示。
- 不让角色玩笑掩盖 `needs_review`、`blocked` 或导出门禁。

| 嫩芽绿 | `#8FC449` | 生长点缀和积极状态 |

不得将阿谷整体改为紫色、蓝灰色或高饱和霓虹色。状态色仍以空谷质量门禁规范为准，角色颜色不能代替红色阻断或黄色待复核提示。

## 六、排版与留白

- 标准母版四周至少保留角色高度 `10%` 的留白。
- 不裁掉双叶冠尖端、手脚或腹部青心种仁。
- 不压缩、拉伸或镜像角色；确需朝向变化时重新制作动作图。
- 浅色背景优先使用透明 PNG/WebP；复杂背景需保证脸部、双叶和青心仍有清晰对比。
- 小于 `64×64` 像素时优先使用应用图标，不直接缩放完整主题立绘。

## 七、界面使用边界

阿谷适合出现于：

- 软件启动页；
- 尚未导入文件的欢迎空状态；
- 使用指引、项目介绍和积极完成状态；
- README、汇报封面和宣传材料。

阿谷不应出现于：

- `blocked` 阻断错误的主视觉；
- 用户需要严肃判断的复核证据区；
- 表格密集区、PDF 坐标叠加层和审计记录内部；
- 任何可能遮挡来源、质量状态或下一步操作的位置。

## 八、禁止改造

- 禁止将阿谷改成人类、动物、机器人或普通卡通米粒。
- 禁止替换双叶冠、透明青心种仁和谷粒身体。
- 禁止添加人类服装、复杂科技装甲或与产品无关的道具。
- 禁止使用山谷意象解释名称。
- 禁止直接用生成模型反复重画标准母版；新动作必须以母版作为唯一参考并核对角色一致性。

## 九、界面动作规范

- 阿谷的动作必须服务于反馈、状态提示、解释或低频愉悦，不为高频操作增加无意义运动。
- 欢迎状态采用“蓄力—行动—落地—收势”；处理中采用脚底有接触感的推进循环；可信完成状态只播放一次庆祝动作。
- 动作以身体压缩与伸展、重心转移、已确认姿态切换、接触阴影和青心光效组合表达，不得只让整张立绘持续上下浮动。
- 普通欢迎循环应包含较长静止段，处理中循环保持克制；`needs_review`、`blocked` 和严肃复核证据区不播放角色动作。
- 界面必须尊重 `prefers-reduced-motion`：停止位移、缩放、旋转和粒子动画，保留能够说明当前状态的静态姿态。
- 当前 Web 动作是基于确认立绘的有限姿态动画，不是独立叶冠、手脚和表情的骨骼绑定；若后续需要更细致的表演，应先建立经过用户确认的分层角色源文件。

## 十、重建方式

品牌衍生资产通过 `tools/build_agu_assets.py` 从四张已确认源图确定性生成。修改脚本后必须整体重建并检查头像、应用图标、启动场景、完成状态和宣传卡，不手工只修一个输出文件。

```powershell
.venv\Scripts\python.exe tools\build_agu_assets.py `
  --standard assets\brand\agu\agu-standard-v1.png `
  --dynamic assets\brand\agu\agu-dynamic-v1.png `
  --complete assets\brand\agu\agu-complete-v1.png `
  --theme assets\brand\agu\agu-theme-from-schedule-v1.png `
  --wordmark assets\konggu-wordmark.png `
  --output-dir assets\brand\agu `
  --tauri-icons-dir src-tauri\icons
```

源图由用户在 2026-08-10 至 2026-08-11 的多轮设计中确认；当前标准角色版本为 `1.0`，视觉使用规范版本为 `1.1`。
