空谷 0.6.0 安装与使用 v1.0

空谷是青禾计划孵化的课表协作产品，用于汇总多人中方、英方课表，生成可核对、可追溯的集体空课表。

一、安装
适用目标：Windows 10 / Windows 11，64位。
双击 Konggu_0.6.0_x64-setup.exe，按提示完成安装。
本版本为所有用户安装，Windows会请求管理员授权；普通账户需要管理员提供授权。安装后日常使用无需以管理员身份启动。
安装包内置Python识别程序、OCR模型和WebView2离线安装组件，无需另装Python、Node或开发工具。若系统已有WebView2，安装程序复用现有组件。
本地候选尚未使用受信任代码签名；如果系统策略阻止运行，请让管理员确认文件来源和校验值，不关闭系统安全防护。

二、第一次使用
1. 从开始菜单打开“空谷 Konggu”，等待本地识别资源准备完成。
2. 在设置中核对学期开始日期、总周数及需生成的周次，以原课表为准。
3. 导入同一批成员的中方、英方课表PDF。建议文件名写清部门、姓名、职务和中方/英方。
4. 生成预览，查看成员配对、缺失文件及待处理问题。
5. 有“待核对”或“无法生成”的问题时，进入原文核对，按提示核实并修正；全部问题解决后再导出正式Excel。
同一成员只有中方和英方都没有课才算空闲。图片识别结果需要原文复核，不能把解析完成当作核对完成。

三、数据在哪里
课表、设置、缓存和处理记录保存在当前Windows用户的数据目录；全用户安装不代表所有人共享同一批课表。
OCR模型可能使用公共的ASCII兼容目录，模型文件本身不包含个人课表。请不要自行删除安装目录里的文件。
需要交接结果时，导出Excel并按组织要求传递；不要把整个用户数据目录当作普通安装材料发送。

四、启动或识别异常
如果软件提示资源准备失败，可先按界面提示重试。仍失败时，关闭本次任务并双击同目录下的 run_konggu_ocr_diagnostic.cmd。
诊断无需先打开空谷，会尝试查找已安装程序，显示结果并生成诊断文本；窗口会保留，便于查看。诊断过程中请等待完成。
将诊断结果中的错误信息反馈给维护者；不要发送原始课表、缓存目录或个人数据库。
如果提示缺少组件，请重新运行完整离线安装包修复安装，不要单独拷贝一个exe或从旧测试包补文件。

五、本候选验证范围
本机已执行的测试、独立目录识别验证、安装包检查及剩余事项，以随包的“交付验收记录”中最终结果为准。
另一台Win10/Win11电脑、实际管理员安装后普通用户切换、物理断网和卸载/重装仍需实机验收。它们尚未验证时，本版本作为交付候选使用，不宣称所有电脑均已兼容。
