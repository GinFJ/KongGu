# 空谷 0.11.0 Windows 试用与验收

## 按一线使用流程操作

1. 从同一个入口打开空谷。导入每人的中方、英方 PDF，文件列表会自动保留。默认在本机记住原件位置 30 天，可在导入前取消。已完成的批次会从上一次核验进度继续。识别中途关掉程序，下次可用恢复的列表重新生成。
2. 遇到教学周越界时，在“课表核验”查看成员、课程、日期和节次。点“核对这门课”打开对应原件。以反馈中的 18 周设置和第 19 周课程为例，先核对校历的第一周周一，再查实际教学周数。校历确有第 19 周才调整周数，并点“保存并重新生成”。日期与周数均正确时，查看和修正具体课程。黄色提示列出的共同覆盖周决定哪些周可以预览和导出。
3. 进入“课表资料 → 课程周视图”，全体成员按节次显示人数。点一节看成员和课程，选择单个成员查看详细课表。“空课结果”仍可按部门、周次和时段查看空闲与有课名单。
4. 再次打开时，若文件移走或此前取消了记住位置，点“关联原件”。已完成任务会逐份核对文件名和内容，可以分次关联。读取旧版本留下的结果需要沿用原数据目录。试用版“本地维护 → 清理本机记录”会清除本批记录和缓存。

## 五人实测

十份真实中英原件在本机离线处理。使用样本库中已有独立逐页视觉标注的五组，先核对每份原件的内容哈希，再逐人核对结果中每个时段。标注来自既有的 AI 原页核对，未由本轮反馈者逐项签认。

| 核对项 | 结果 |
| --- | --- |
| 成员、原件、可预览时段 | 5 人，10 份 PDF，273 个时段 |
| 人员与时段的组合 | 1,365 个，每人每格均核查有课与空闲两列 |
| 有课成员误入空闲名单 | 0 |
| 空闲成员误入有课名单 | 0 |
| 人工核验范围 | 745 项。实际工作人员仍需核对课程并处理每项需复核的问题。 |

这十份 PDF 共 16 页，全部触发图片识别。使用独立空缓存，从开始处理到取得第一份预览结果用时 **19 分 10 秒**，同一环境连续重算两次分别为 **35.61 秒、35.08 秒**。计时期间本机也在构建软件；这里记录这组图片课表在本机的等待时间。

另用两版冻结程序做有缓存的对照。为两版各复制相同十份原件的已识别缓存，分别启动新进程，在本地识别服务就绪后计时。按旧版、新版、新版、旧版顺序运行，四次均按 1,365 项标注复核名单。

| 版本 | 第一次重新生成 | 第二次重新生成 |
| --- | ---: | ---: |
| 0.10.0 | 41.14 秒 | 41.82 秒 |
| 0.11.0 | 34.79 秒 | 35.90 秒 |

对同一五人批次，分别从三个新建的本地服务对象恢复最近任务、预览和原件核验数据，耗时 0.59 至 0.73 秒。该计时从查询上批任务开始，不含桌面和识别程序启动。对六次相邻的原件确认交替记录完整回复和简短回执。完整回复约 1,279,400 字节，耗时 0.50 至 0.55 秒。新版回执 358 字节，耗时 0.25 至 0.29 秒。两条路径都校验原件哈希、任务修订和核验项。

## 用户操作验证

五名虚构成员分属两个部门，十份输入包含一条特意放在第二周的课程。以一周校历生成，页面列出该课程及其 PDF，点击后定位到原件。把教学周改为 18 周后重新生成，越界提示解除。按节查看多人名单、切换单人课表、重开继续核验和 Excel 导出均纳入此流程。

在 Chrome 中运行实际界面，识别和核验由冻结程序完成。原生文件选择与保存位置由测试传入。刷新选件页后保留十份文件，确认第一项后关闭页面及识别进程，再次打开时进度为 1/11。测试同时撤掉旧的文件读取权限，确认原页可按原件哈希重新打开。最终 11/11，导出完整明细 Excel。重新打开工作簿核对 11 张工作表和全部五名合成成员。检查了 1280 × 820 与 1080 × 720 两种窗口尺寸，最窄尺寸下逐节人数完整可见。[越界课程与原件入口](images/0.11.0/semester.png) · [五人课程周览](images/0.11.0/week-1080.png) · [展开时段名单](images/0.11.0/roster.png)

## Windows 本地交付

交付目录为 `build/candidates/0.11.0-windows`。完整安装器供 Windows x64 使用。免安装目录的 `试用空谷.cmd` 与 `portable` 一起使用，该入口将本机资料保存在同目录的 `trial-data`。十份示例 PDF 全为虚构成员。安装版使用原有应用数据目录。若上一次用的是旧版免安装试用入口，想在新目录接着做，可先关闭旧版，将旧目录的 `trial-data` 复制到尚未启动过的新版试用目录，再打开 `试用空谷.cmd`。旧目录可保留。
