## 一、事实状态

| 状态 | 定义 | 可以声明的内容 |
|---|---|---|
| 已提交 | 存在可追溯提交 | 代码已进入指定提交 |
| 已验证 | 存在当前测试、审计、构建或产物证据 | 对应范围通过本次验证 |
| 在研 | 工作区存在实现，但尚未完成交付验证 | 功能正在开发或验证 |
| 历史形态 | 过去存在，当前已替换或删除 | 仅作历史说明 |
| 待确认 | 现有材料不足 | 需要补充证据 |
| 未验证 | 已有主张，但本轮未执行验证 | 不得声明通过 |

## 二、解析质量状态

### accepted

满足：

- 输入完整；
- 身份和课表类别可靠；
- 关键字段通过规则或人工核验；
- 不存在影响正式结果的问题。

### needs_review

适用于：

- 文件可处理；
- 结果可生成；
- 但身份、课程块、周次、时间、版式或低置信 OCR 需要人工确认。

处理要求：

- 界面显示问题和原文依据；
- 完成人工复核并记录修正原因；
- 重新计算受影响结果；
- 问题解决前不得标记正式完成。

### blocked

适用于：

- 缺少必要文件；
- 已选择的文件不存在、无法读取，或不同目录中有同名 PDF 导致原文无法可靠对应；
- 身份冲突；
- 课表类型无法确认；
- 文件损坏或解析失败；
- 存在会导致正式结果错误的问题。

处理要求：

- 不生成正式结果；
- 不允许通过普通“确认”直接放行；
- 修复源文件、身份、配置或解析结果后重新处理。

## 三、时间、来源与完成状态

0.6.9 的英方时间与分页检查：无编号午间课程只在完整钟点轴与实际格边界共同通过校验时映射到已确认的午间两节；不满足条件继续阻断。`ENGLISH_DATE_ROW_UNRESOLVED` 表示可见日期行未可靠配对，必须重解析或补证。详情浮层仅在原 PDF 完整底层格线及无内容证据成立时生成信息项 `ENGLISH_OVERLAY_EMPTY_VERIFIED`；否则保留 `ENGLISH_GRID_OVERLAY` 阻断，不能将清除浮层后的白色像素当作空课。

任务 `completed` 必须在复核凭据复用、问题及文件状态全部保存后发布。它表示处理已结束，不表示质量必然为 `accepted`；前端和导出接口仍检查实时 `can_export`、签名及全部未解决问题。

### 准确率声明

- PDF Inspector 的 `confidence` 只表示通用 PDF 类型分类置信度，不是课表识别准确率，也不直接决定质量门禁。
- 自动解析成功不等于准确。
- 自动接受率不等于准确率。
- 测试通过数和样本数量不等于准确率。
- 只有经过人工核验的真值数据才能支持准确率结论。
- 准确率必须注明样本范围、时间、提交、配置、核验方法和限制。

## 四、导出门禁

正式导出前必须确认：

- 无未解决的 `blocked`；
- 无未解决的 `needs_review`；
- 结果仍匹配当前来源、有效学期设置与解析签名；过期结果须重新解析，不能因历史质量为`accepted`继续导出；
- 成员课表配对完整；
- 来源记录完整；
- 人工修正可追溯；
- 受影响结果已重新计算；
- 导出文件实际打开并完成渲染检查。

## 五、同页字形证据与专项复核

同页两处原OCR规范标记可以为候选区域提供字形证据。候选不能再作为新的参照；覆盖分数只表示形状符合当前规则，不是语义核验或准确率。

| 处理分支 | 预览行为 | 证据动作 |
|---|---|---|
| 通过场景与完整区域检查的矢量字形比对 | 预览已按非课程排除相应区域；结果仍待专项核对 | `excluded_from_preview_occupancy`，`occupancy_changed=true` |
| 同页像素字形建议 | 保留原占用，仅提示疑似非课程标记 | `suggested_nonclass_requires_review`，`occupancy_changed=false` |

两种动作都保留原OCR、页码、区域、规范标签、两处参照及分数，并与来源哈希、解析签名和OCR签名绑定。每项生成独立的`VISUAL_NOTICE_CONSENSUS_REVIEW`：默认未确认、阻止正式导出，相关文件显示`needs_review`。普通图片页复核不能替代这项专项核对；确认一项也不会自动解除其他未解决问题。

核对时对照原页、周次与节次，以及同页两处规范标记。确认提示只记录本次核对，不会重新修改占用：矢量分支仍使用已排除的预览，像素分支仍保留原占用。

当前没有针对这类区域的独立人工排除／恢复界面。若不同意矢量预览排除，或确认像素建议区域确为非课程且需要排除，应保留待复核，修复后重新解析；不能声称现有确认按钮或课程修正入口已经提供该能力。附着细小笔画仍可能高分误配，相关反例用于检验专项门禁，不能据此宣称识别缺陷已消除。
