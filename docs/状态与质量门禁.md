# 状态与质量门禁

## 0.13.1 身份与冲突核对

如果不同部门的同名成员提交了内容完全相同的课表，程序列出两份资料的身份，暂停导出，待制表人核实原件后重新导入。打开旧批次时，也会检查已记录的文件指纹。日期批次中的课程冲突按实际日期、节次和成员列出，选区外的冲突不会阻止本次排班。

## 0.13.0 日期批次

每个成员初始待确认。所选区间缺少日期依据时，由制表人核实、补齐有课节次或确认确实无课，再确认该成员。改动其占用后需要重新确认。原件无效、身份冲突或学期越界等阻断仍需处理。桌面预览和 Excel 导出共同检查全员确认、来源及质量状态。旧批次沿用原有逐项核验。

## 0.11.0 的周次提示和续做

“先核对学期日期”从产生越界提示的同一组课程记录列出成员、课程、周次、节次和原件入口。工作人员可对照原页修正课程，也可按校历修改学期并重新生成。出现必须处理的问题时，结果页面标注“仅供预览”。共同覆盖的工作周之外不推断空闲。重新打开上批任务会取回已有核验进度，学期或解析签名不相容时提示重新生成。

## 0.10.0 逐项核验

解析结束后，每份原件的课程进入本任务的人工核验队列。能定位到同一原页课程格、对应字段一致的多个周次合为一项，核验时须核对列出的周次。缺少定位框时各条记录分别核验。核验绑定来源和课程内容，修正发生变化的课程需重新对照原件。

正式导出检查解析质量和逐项进度。解析状态为 `accepted` 时仍需确认全部课程。零课程文件按原有解析及人工核对无课程规则处理。只识别到一位成员时提示检查批次范围。成员缺少一方有效课表时，须处理缺项后再导出。

选择单个部门改变周表、人员名单和 Excel 的数据范围。正式导出仍要求整批完成核验。部门按已识别的成员身份和实际占用时段筛选，原课表未覆盖的时段保留为未覆盖。青禾模板按工作日和大节排班，完整工作簿提供逐节明细。

## 0.9.0 可选 AI 复核

`AI_PAGE_REVIEW_REQUIRED` 为阻止正式导出的 warning。AI 发现差异/不确定、校外记录或本地独有占用时生成该提示；采用建议只补录并重算，不自动确认。核对后可通过现有确认入口记录结果；所有 error 仍不能直接确认。重导入同源且仍有差异的历史 AI 观察会重新提示。完整说明见[AI 使用说明](AI识别使用说明_0.9.0.md)。

核对日期：2026-11-16。当前解析签名 71，AI 提示版本独立为 `timetable-page-v1`，实际范围见[0.9.0 验收](交付验收_0.9.0_v1.0.md)。重复读取缓存仍有差异时重新要求复核，不继承过期确认。历史段落保留规则引入时间。

0.6.7 补充：已核对的 warning 以不可变审计凭据关联原文件内容、成员、完整占用、全部问题、日历和解析签名。同一批材料重新生成时自动复用；任一依据变化即重新要求核对，error 不得复用放行。凭据随本机任务记录保留，清理记录后需重新核对。

## 一、事实状态

| 状态 | 定义 | 可以声明的内容 |
|---|---|---|
| 已提交 | 存在可追溯提交 | 代码已进入指定提交 |
| 已验证 | 存在当前测试、审计、构建或产物证据 | 对应范围通过本次验证 |
| 在研 | 工作区存在实现，但尚未完成交付验证 | 功能正在开发或验证 |
| 历史形态 | 过去存在，当前已替换或删除 | 仅作历史说明 |
| 待确认 | 现有材料不足 | 需要补充证据 |
| 未验证 | 已有主张，但本轮未执行验证 | 不得声明通过 |

## 二、解析质量状态

### accepted

满足：

- 输入完整；
- 身份和课表类别可靠；
- 关键字段通过规则或人工核验；
- 不存在影响正式结果的问题。

### needs_review

适用于：

- 文件可处理；
- 结果可生成；
- 但身份、课程块、周次、时间、版式或低置信 OCR 需要人工确认。

处理要求：

- 界面显示问题和原文依据；
- 完成人工复核并记录修正原因；
- 重新计算受影响结果；
- 问题解决前不得标记正式完成。

### blocked

适用于：

- 缺少必要文件；
- 已选择的文件不存在、无法读取，或不同目录中有同名 PDF 导致原文无法可靠对应；
- 身份冲突；
- 课表类型无法确认；
- 文件损坏或解析失败；
- 存在会导致正式结果错误的问题。

处理要求：

- 不生成正式结果；
- 不允许通过普通“确认”直接放行；
- 修复源文件、身份、配置或解析结果后重新处理。

## 三、时间、来源与完成状态

0.6.9 的英方时间与分页检查：无编号午间课程只在完整钟点轴与实际格边界共同通过校验时映射到已确认的午间两节；不满足条件继续阻断。`ENGLISH_DATE_ROW_UNRESOLVED` 表示可见日期行未可靠配对，必须重解析或补证。详情浮层仅在原 PDF 完整底层格线及无内容证据成立时生成信息项 `ENGLISH_OVERLAY_EMPTY_VERIFIED`；否则保留 `ENGLISH_GRID_OVERLAY` 阻断，不能将清除浮层后的白色像素当作空课。

任务 `completed` 必须在复核凭据复用、问题及文件状态全部保存后发布。它表示处理已结束，不表示质量必然为 `accepted`；前端和导出接口仍检查实时 `can_export`、签名及全部未解决问题。

### 准确率声明

- PDF Inspector 的 `confidence` 只表示通用 PDF 类型分类置信度，不是课表识别准确率，也不直接决定质量门禁。
- 自动解析成功不等于准确。
- 自动接受率不等于准确率。
- 测试通过数和样本数量不等于准确率。
- 只有经过人工核验的真值数据才能支持准确率结论。
- 准确率必须注明样本范围、时间、提交、配置、核验方法和限制。

## 四、导出门禁

正式导出前必须确认：

- 无未解决的 `blocked`；
- 无未解决的 `needs_review`；
- 结果仍匹配当前来源、有效学期设置与解析签名；过期结果须重新解析，不能因历史质量为`accepted`继续导出；
- 成员课表配对完整；
- 来源记录完整；
- 人工修正可追溯；
- 受影响结果已重新计算；
- 导出文件实际打开并完成渲染检查。

## 五、同页字形证据与专项复核

同页两处原OCR规范标记可以为候选区域提供字形证据。候选不能再作为新的参照；覆盖分数只表示形状符合当前规则，不是语义核验或准确率。

| 处理分支 | 预览行为 | 证据动作 |
|---|---|---|
| 通过场景与完整区域检查的矢量字形比对 | 预览已按非课程排除相应区域；结果仍待专项核对 | `excluded_from_preview_occupancy`，`occupancy_changed=true` |
| 同页像素字形建议 | 保留原占用，仅提示疑似非课程标记 | `suggested_nonclass_requires_review`，`occupancy_changed=false` |

两种动作都保留原OCR、页码、区域、规范标签、两处参照及分数，并与来源哈希、解析签名和OCR签名绑定。每项生成独立的`VISUAL_NOTICE_CONSENSUS_REVIEW`：默认未确认、阻止正式导出，相关文件显示`needs_review`。普通图片页复核不能替代这项专项核对；确认一项也不会自动解除其他未解决问题。

核对时对照原页、周次与节次，以及同页两处规范标记。确认提示只记录本次核对，不会重新修改占用：矢量分支仍使用已排除的预览，像素分支仍保留原占用。

0.8.0 增加独立的区域排除/恢复入口：原图已自动排除的课程可按证据范围恢复，仍计占用的非课程区域可实际排除。操作必须填写原因并自动重算，只解决明确选中的区域提示；其他图片页复核和阻断继续保留。普通确认按钮仍不改变占用。无区域证据的漏课可按原件页码补录，误识别课程可删除并恢复。详见[人工修正使用说明](人工修正使用说明_0.8.0.md)。

0.7.1：唯一互补来源补全身份为信息项；日历说明和校外地点的原格双次重识别保留原始观察及源哈希证据。缺笔画的跨页代码若缺少完整课程格支持，继续保留 `ENGLISH_CELL_TEXT_INCOMPLETE`。确认这种提示只表示已核对占用，不替换课程名称；记录原因和操作者。新来源、解析签名或批次上下文改变后不能静默复用旧确认。
