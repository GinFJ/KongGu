# 状态与质量门禁

## 一、事实状态

| 状态 | 定义 | 可以声明的内容 |
|---|---|---|
| 已提交 | 存在可追溯提交 | 代码已进入指定提交 |
| 已验证 | 存在当前测试、审计、构建或产物证据 | 对应范围通过本次验证 |
| 在研 | 工作区存在实现，但尚未完成交付验证 | 功能正在开发或验证 |
| 历史形态 | 过去存在，当前已替换或删除 | 仅作历史说明 |
| 待确认 | 现有材料不足 | 需要补充证据 |
| 未验证 | 已有主张，但本轮未执行验证 | 不得声明通过 |

## 二、解析质量状态

### accepted

满足：

- 输入完整；
- 身份和课表类别可靠；
- 关键字段通过规则或人工核验；
- 不存在影响正式结果的问题。

### needs_review

适用于：

- 文件可处理；
- 结果可生成；
- 但身份、课程块、周次、时间、版式或低置信 OCR 需要人工确认。

处理要求：

- 界面显示问题和原文依据；
- 完成人工复核并记录修正原因；
- 重新计算受影响结果；
- 问题解决前不得标记正式完成。

### blocked

适用于：

- 缺少必要文件；
- 身份冲突；
- 课表类型无法确认；
- 文件损坏或解析失败；
- 存在会导致正式结果错误的问题。

处理要求：

- 不生成正式结果；
- 不允许通过普通“确认”直接放行；
- 修复源文件、身份、配置或解析结果后重新处理。

## 三、准确率声明

- PDF Inspector 的 `confidence` 只表示通用 PDF 类型分类置信度，不是课表识别准确率，也不直接决定质量门禁。
- 自动解析成功不等于准确。
- 自动接受率不等于准确率。
- 测试通过数和样本数量不等于准确率。
- 只有经过人工核验的真值数据才能支持准确率结论。
- 准确率必须注明样本范围、时间、提交、配置、核验方法和限制。

## 四、导出门禁

正式导出前必须确认：

- 无未解决的 `blocked`；
- 无未解决的关键 `needs_review`；
- 成员课表配对完整；
- 来源记录完整；
- 人工修正可追溯；
- 受影响结果已重新计算；
- 导出文件实际打开并完成渲染检查。
