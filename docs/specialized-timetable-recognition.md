# 特化课表识别规则

本页随0.5.30文档整理更新（2026-11-02），按现有0.5.29实现、解析签名65说明路由与边界。本次未修改识别规则或重跑算法；结果及限制见[0.5.29验收记录](迭代验收_0.5.29_v1.0.txt)与[复用性验证](复用性验证.md)。

版式profile用于选择已有解析路径，不表示所有输入都应先做OCR，也不表示命中版式即可接受结果。

## 当前路由

1. 校验来源内容、身份、课表类别与文件完整性。解析缓存命中也必须先校验来源，缓存及修正须匹配相应签名。
2. 优先尝试PDF文本层及其坐标结构：中方表格／旧版网页课表、英方日期网格分别有对应路径。
3. 文本不足、解析为空，或已有结果稀疏需要补扫时，才使用本地OCR及坐标布局。版式判断优先读文本，文本不可用时才补OCR项目；不默认对所有文件识别图片。
4. 中方OCR表格路径先尝试可见边框约束的视觉占用，再按条件回退到整学期坐标网格或其他兼容路径；英方OCR路径优先使用日期与节次坐标网格，不能让展平文本抢先掩盖跨节课程。
5. 输出课程块／视觉占用与来源证据，随后由工作流检查成员完整性、问题状态和导出门禁。解析得到占用不等于结果已获核验。

主编排位于`core/schedule_core.py`。可见边框辅助集中在`core/bordered_timetables.py`；同页像素建议和纯矢量字形处理分别位于`core/visual_notice_consensus.py`、`core/vector_notice_consensus.py`。

## Profile 1：中方整学期横向大表

ID：`cdut_undergrad_full_term_cn`

版式线索包括本科学生课表标题、星期栏、周／节栏、周次或日期，以及节次组。学年标题不是固定年份；周次必须结合原页与有效校历判断，不能统一假设18、20或21周。

当前处理：

- 有可用文本层时，优先按文本坐标与单元格边界解析。
- 进入OCR表格路径后，优先寻找可见横竖线、真实不等宽列与正文行；利用左侧周次锚点定位行轴，不按页面固定位置或等宽列补格。
- 边框路径按可见正文行和周次锚点确定范围，只计算实际有边界的单元格；右侧边框缺失时不擅自向外补列。未形成可靠边框结果时，按已有条件使用兼容路径，不据此推断任意版式均受支持。
- 日期只有月／日时结合学期起点、表内周次确定年份，跨年日期不能一律套用学期开始年份。
- 视觉占用路径根据格内内容判断是否占用，课程名可记为`视觉表格占用`，不承诺恢复完整课程名称。
- 节次组为`1-2`、`3-4`、`午`、`5-6`、`7-8`、`9-11`。中方“午”列不计占用；“校外”沿用既定业务排除口径，本轮整理不改变该规则。
- 规范独立告示与真实课程名分别处理，不能因课程名含“教研”“考试”等子串便清空课程。含数字的短码也不能一概视为教室或乱码。

同页字形处理在物理区域确定后执行。满足保守场景资格的纯矢量页，使用原页面DisplayList裁取完整字形，与同页两处原OCR规范标记比对；不根据绘图接口丢失的子路径信息重建原图。像素建议仍要求OCR框完整。矢量判断可排除待复核预览中的区域，像素建议保留占用，两者均保留专项复核，详见[状态与质量门禁](状态与质量门禁.md)。

需要复核的情况包括周次或边界不可靠、内容超页／裁切、身份冲突、低置信占用和字形推断。只识别出少量周次时应结合完整性规则判断，不能以存在课程块替代全表核验。

## Profile 2：英方网页截图式课表

ID：`cdut_sino_british_english_web`

版式线索包括`Sino-British`、`Timetable for`、星期及日期块；典型表格包含第1至11节，也有无编号的午间格与空白间隔列。

当前处理：

- 优先按PDF文本坐标与单元格边界解析；需要OCR时使用日期网格，以真实日期确定周次，不能把页面顺序当作第几周。
- 日期缺少年份时结合有效学期配置，显式年份保留。日期与星期必须相互校验；缺失标签的补全受现有日期结构约束。
- 优先用可见表头边界定位节次，保留空白间隔列。表头残缺时，从各页完整候选中选择统一模板，避免续页先后顺序决定解析结果。
- 合并课程格结合当前行真实分隔与内容跨界证据判断；不能简单扩大列距，将课程合并穿过空白间隔。
- 表头、时间与课程正文按区域区分，避免残缺时间或单个数字被当作课程。早期脏表头token兼容仍受布局条件约束，噪声字符串本身不是真值。
- 稀疏结果可能触发OCR补扫；课程块数量不是接受条件。图片页或实际OCR回退来源仍需工作流复核。
- 无编号午间格若有课程，应保留原页占用；原页没有单独钟点时展示“午间格（钟点待核）”，不得强行映射标准节次或放行正式导出。

## Profile 3：英方中文周视图

ID：`cdut_sino_british_english_week_grid`

版式线索包括第N周、周一至周日及课程内容。优先使用可用日期网格；没有日期网格时才按第N周网格解析。仍须检查课程码、非课程文本和有效学期范围，不能因命中profile跳过质量门禁。

## 错误样本与来源边界

- 同内容被登记为不同成员时应显式记录冲突，不能当作两份独立来源。
- 正文与文件名身份冲突时不能通过视觉恢复换成另一人的占用，须核对源文件和成员对应关系。
- 解析失败、低置信、裁切与缺失文件必须在问题和文件记录中可见；不能把所有源材料问题都归因于OCR。
- 来源、解析器、OCR或配置变化后须重新评估缓存、证据与人工修正。

## 验证与历史说明

早期说明中的“21周行轴”及“20份图片／低文本样本中19份产生占用”属于旧实现与旧材料记录，不是当前所有输入的固定契约或准确率。兼容路径仍可能带有旧版布局假设，当前优先边框路径的支持范围不能外推到所有课表。

当前可引用的验证是0.5.29冻结记录：74份原PDF、37个成员组，第10周740项指定真值对照，以及现有材料受控变体检查。本次文档整理沿用这些证据，没有新跑OCR、扩充未见样本或重新验收算法。全学期独立真值、未见字体／混合页、附着细笔画风险和发布级验证仍待完成，详见[验收记录](迭代验收_0.5.29_v1.0.txt)。
