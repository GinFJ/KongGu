# 特化课表识别规则

这批样本不应该按“通用 OCR 文本抽取”处理。更可靠的做法是先识别版式 profile，再分派专用解析器。

## Profile 1: 中方整学期横向大表

ID: `cdut_undergrad_full_term_cn`

识别锚点：

- 标题包含 `成都理工大学本科学生课表（2025-2026学年第二学期）`
- 顶部有 `星期一` 到 `星期日`
- 左侧有 `周/节`、第 `1周` 到第 `21周`
- 节次结构固定为 `1-2`、`3-4`、`午`、`5-6`、`7-8`、`9-11`
- 页面底部有课程图例，含课程简称、课程名称、课程编号、教室等

程序策略：

1. 渲染页面为图片，优先识别表格横竖线。
2. 用左侧周次和日期列定位行轴。
3. 用顶部星期和节次组定位列轴。
4. OCR 课程文本可信时按格子边界筛 OCR token。
5. OCR 课程文本低置信时，回退到视觉表格占用：按虚拟格子内的文字像素判断该时段是否被占用，课程名记为 `视觉表格占用`。
6. 过滤 `午`、`校外`、`教研`、`期末周`、`考试周`、节假日、运动会、`不排课`。
7. 格子短码不能简单当乱码，例如 `高L31`、`大R418`、`写L26`、`国L44`、`E2B101`、`TT05` 都可能是有效占用的一部分。
8. 底部图例是课程白名单来源，后续应把格子短码和图例简称/课程名关联。

当前风险：

- 普通 OCR 会把格子内容拆成短碎片，通用低置信规则容易误杀。
- 如果不先切格子，底部图例、表头、日期、教室号会和课程格子混在一起。
- 整学期表如果只解析出少量离散周次（例如 6-8 个周次），不能直接进入空课计算；当前会先尝试视觉表格占用恢复，恢复失败才进入人工复核。

## Profile 2: 英方网页截图式课表

ID: `cdut_sino_british_english_web`

识别锚点：

- 页面包含 `CDUT Sino-British Collaborative Education - Student Website`
- 标题为 `Timetable for <name>`
- 有 `Start` / `End` 日期
- 每周按 `Monday` 到 `Friday` 分块
- 列为第 `1` 到第 `11` 节

程序策略：

1. 以真实日期作为周次来源，禁止用页面顺序推第 1 周。
2. 从脏表头 token 中恢复节次：
   - `A` 视为 `1`
   - `.4` 视为 `4`
   - `3...4` 视为 `3`、`4`
   - `.5..6` 视为 `5`、`6`
   - `98:105-`、`10:66-`、`20155` 等时间 OCR 噪声可作为节次列锚点
3. 如果某个表头残缺，用同页后续完整表头校准列中心。
4. 过滤 `Teacher`、`Room`、`Group`、`Home`、`Start`、`End`、纯时间、纯数字和教室号。
5. OCR 占用少于 8 条时进入复核，不自动计入。

当前实现状态：

- 已支持脏表头节次恢复。
- 已支持用完整表头校准残缺表头。
- 已支持 `20260506`、`202605-08` 这类 OCR 日期 token。
- 已支持时间行 OCR 噪声反推节次列，脱敏英方样本已从低覆盖转为自动接受。

## Profile 3: 英方中文周视图

ID: `cdut_sino_british_english_week_grid`

识别锚点：

- 有 `第N周`
- 有 `周一` 到 `周日`
- 有英方课程短名

程序策略：

- 优先按日期网格解析。
- 没有日期网格时才回退到第 N 周网格。
- 仍然必须通过非课程文本过滤。

## 分派顺序

推荐顺序：

1. 判断文件名或目录中的 `中方` / `英方`。
2. 对无文本层或低文本 PDF 运行 OCR layout。
3. 通过锚点检测 profile。
4. 分派专用解析器。
5. 每个 profile 输出自己的置信度和复核原因。

## 错误样本拦截

这类素材库里会混入错误样本，不能把所有异常都当成 OCR 解析问题。

- 同一份 PDF 内容如果被复制成两个不同姓名，审计工具用 `content_hash` 标记 `duplicate_content` 和 `duplicate_name_mismatch`。
- 中方 OCR 正文姓名如果和文件名姓名不一致，解析器直接跳过，不允许把别人的课表算到当前成员。
- 审计报告必须输出错误原因，避免后续把“源文件错”误判为“解析器漏识别”。

## 当前复核边界

`cdut_undergrad_full_term_cn` 已加入视觉表格占用 fallback：当 OCR 课程文本低置信时，程序会渲染页面、识别横竖线、按 21 周和 7 天节次格子判断占用。该路径不依赖课程名识别，适合空课计算，但不能还原完整课程名称。

仍需复核的边界：

- 正文姓名与文件名姓名不一致，视为源文件错误，不走视觉恢复。
- 视觉表格无法稳定检测 21 周行轴或 7 天列轴时，不自动计入。
- 视觉 fallback 只输出占用，不输出真实课程名。

当前样本库验证：20 个图片型/低文本 PDF 中，19 个可自动产出占用；成员A中方样本因正文姓名为成员B，仍进入 `needs_review_name_mismatch`。
