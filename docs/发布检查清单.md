# 空谷发布检查清单

## 一、发布身份

- [ ] 应用版本与安装包版本一致。
- [ ] 已记录对应 Git 提交。
- [ ] 当前工作区无未经说明的改动。
- [ ] 发布内容只包含本次授权范围。
- [ ] README、界面、配置和实际行为一致。
- [ ] package、package-lock 根节点/根包、Cargo 的 konggu 条目、Cargo.lock 和 Tauri 共六处版本值一致；当前解析签名、候选来源及未提交差异单独记录。
- [ ] MEMORY、变更记录、项目志、测试说明、使用说明和交付记录已同步；旧版验收与本版证据分开。

## 二、测试与构建

- [ ] Python 测试通过。
- [ ] 脱敏真实样本回归通过。
- [ ] 前端构建通过。
- [ ] 桌面层、sidecar 或命令协议检查通过。
- [ ] Cargo 或对应桌面构建检查通过。
- [ ] 离线资源完整。
- [ ] 构建前 `tools/verify_release_bundle.py --source-only` 通过；它只检查源码、配置与资源清单，不能代替实际 worker、完整安装包和隔离运行检查。
- [ ] 安装包构建成功。
- [ ] WebView2 Standalone Runtime 已随安装包嵌入，安装脚本不包含运行时在线下载路径。
- [ ] `konggu-worker.exe` 已使用受信任证书签名。
- [ ] `konggu.exe` 已使用受信任证书签名。
- [ ] NSIS 安装器已使用受信任证书签名。
- [ ] 三类签名产物均通过 `signtool verify /pa`。
- [ ] 必要验证的命令、环境和结果已记录。

## 三、功能流程

- [ ] 全新用户目录可以启动。
- [ ] 断网环境可以启动和使用。
- [ ] 可以导入支持的课表。
- [ ] 输入预检状态正确。
- [ ] 正常、待复核、阻断和失败状态显示正确。
- [ ] 人工复核和修正可追溯。
- [ ] 正式导出门禁有效。
- [ ] Excel 或其他成果实际打开并检查。

## 四、隐私与安全

- [ ] 安装包不包含真实课表。
- [ ] 日志不包含真实姓名、原始路径和完整课程文本。
- [ ] 示例、测试和文档已脱敏。
- [ ] 不存在未经授权的数据上传。
- [ ] 不存在运行时模型下载或隐式联网。
- [ ] 临时文件和缓存位置已检查。
- [ ] 已执行 `.venv\Scripts\python.exe tools\check_repo_privacy.py` 和发布前 `npm.cmd run check:privacy:history`；未跟踪的待交付文件也已单独检查，不能被默认受跟踪文件扫描遗漏。

## 五、发布记录

- [ ] 产物名称已记录。
- [ ] 版本号已记录。
- [ ] Git 提交已记录。
- [ ] 文件大小已记录。
- [ ] SHA-256 已记录。
- [ ] 构建环境已记录。
- [ ] 安装和断网验证结果已记录。
- [ ] 已知问题已记录。
- [ ] 回滚方式已记录。
- [ ] 发布授权已确认。

## 六、未通过处理

任一必要项未运行或失败时：

1. 标记为“未验证”或“验证失败”；
2. 记录命令、错误和影响；
3. 不得以其他部分通过代替整体通过；
4. 不得声明正式发布。
