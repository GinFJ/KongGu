# 空谷协会试运行检查表

每位试用成员选择一组已知正确结果的中方、英方课表，按顺序完成：

- [ ] 导入课表，确认文件类型和组合成员标识正确。
- [ ] 观察逐文件、逐阶段进度；记录不可理解的阶段文案。
- [ ] 对一个待确认问题打开 PDF 复核，点击课程块与来源框互相定位。
- [ ] 修改课程、周次或节次，确认仅受影响成员的空闲结果变化。
- [ ] 关闭并重新打开应用，确认任务、问题和人工修正仍在。
- [ ] 重新导入相同 PDF，确认相同 parser signature 自动复用修正。
- [ ] 模拟一个无法解析文件，确认可仅重试失败文件。
- [ ] 在存在阻断或未确认问题时尝试导出，确认应用拒绝生成正式结果。
- [ ] 所有问题修复或确认后导出，核对工作表和关键空闲槽。
- [ ] 断网启动，确认资源检查、PDF 复核、OCR 和导出均可用。

记录字段：试用人编号、Windows 版本、CPU、PDF 数量、总耗时、峰值内存、问题描述、是否阻断工作、建议。

通过标准：3～5 人全部完成主流程；无错误文件误放行；重启后修正不丢失；导出抽查一致；无运行时下载。
