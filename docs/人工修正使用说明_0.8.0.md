# 0.8.0 人工修正使用说明

在“核对问题 → 原文核对”选择具体原件。右侧提供已有课程编辑，以及“补录与删除”。原 PDF 始终保持不变。

## 补录漏课

展开“补录漏课”，填写课程名称、原件页码、周次、星期、节次和操作原因，选择“保存补录并重算”。成员及中英类别沿用当前原件，不能随意补到另一个人。一次补录对应一周一天，可填写多个节次，如 `3,4`；重复多周的漏课按周补录。

午间第一节填写 `12`，对应 12:40–13:25；第二节填写 `13`，对应 13:30–14:15。原件页码从 1 开始。周次必须在当前校历内，不能通过补录扩大英方原件实际覆盖范围。同一来源同一时段已有记录时，先修改已有记录，不能重复添加。

课程周视图按实际时间排列，午间会显示在下午前面。不连续的节次会分段显示，中间空档保留；这种记录请在“原文核对”修改，避免拖动一段时影响其他节次。

## 删除误识别记录与恢复

在“课程记录”选中要删除的记录，核对显示的周次、星期、节次，填写原因后点击“删除当前误识别记录”。操作只移除选中记录的占用，不删除原件、不删除成员；如果一门课被拆成多条节次记录，应逐条核对处理。

误删后展开“已删除记录”，选择记录，填写恢复原因，再点“恢复记录并重算”。若同一来源的该时段已经补录其他记录，程序会拒绝重复恢复。

## 恢复自动误排除的区域

有原图区域证据时，展开“自动排除与疑似非课程区域”，按页码、周次、星期、节次选中区域。原件实际有课程而程序已自动排除时，填写真实课名和操作原因，点“恢复为课程并重算”。时间及区域范围来自该条原图证据，不由按钮猜测。

若程序仅提示疑似非课程、仍保留占用，而你核实它确为教研或节日说明，则点“确为非课程，排除并重算”。这会真正改变占用；普通“确认已核对”按钮只记录检查结论。

没有区域证据入口的漏课，可直接在当前原件中补录。补录不能代替缺页或损坏原件的完整性检查。

## 重算、记录与撤销

每次操作成功后，课程占用、成员空闲、预览及导出数据一并更新。多节课程在 Excel 课程明细中按节次展开，每节对应实际时间。历史保留操作、修改前后、原件关联、原因、操作者和时间；Excel 的“人工修正历史”也会包含这些内容。

“撤销本原件最近一次课程操作”适用于补录、删除、恢复、区域处理。撤销本身也留记录；如果课程又被后续字段编辑改变，会拒绝覆盖，需直接处理当前记录。已有课程的课名、周次、星期、节次仍通过上方字段编辑修正。

完全相同的原件、身份、学期与解析规则再次导入时，仅在前置课程状态和区域证据一致的情况下依序复用操作。文件内容、身份、解析规则或区域证据变化后，需要重新核对。清理本机记录会清除修正历史；软件重启后应重新导入原件，再查看复用后的结果。

## 仍然不能直接放行的情况

缺少中方或英方原件、身份冲突、页面裁切、内容遮挡、解析失败及原件未覆盖目标日期，仍按质量门禁处理。修改一条课程不会解除这些问题。课程变动后，相关图片页或冲突提示可能需要重新核对，未解决的问题继续阻止正式导出。
