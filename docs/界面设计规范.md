# 空谷界面设计规范

> 规范版本：1.0
> 生效日期：2026-08-11
> 适用范围：空谷 Windows 桌面端及其界面验收

## 一、设计定位

空谷是青禾计划孵化的课表协作产品。界面采用“有机、编辑式任务工作台”方向：墨绿承接青禾的生长意象，暖白纸张承载需要核对的事实，阿谷只在欢迎、处理和可信完成等积极状态出现。

界面首先回答三个问题：现在处理到哪一步、结果是否可以使用、下一步该做什么。视觉装饰不得遮挡文件状态、问题原因、来源和操作入口。

## 二、信息架构

主流程固定为：

```text
导入课表 → 生成空课表 → 处理问题 → 原文核对 → 导出空课表
```

- 左侧栏承载导入、生成、重新处理、导出、学期设置和本地识别状态。
- 顶部状态区说明当前任务和结果状态，不展示任务 ID、解析签名等内部字段。
- 文件带展示本次输入来源；结果区承载六个稳定视图。
- 最近操作只提供辅助反馈，在最小高度下可以隐藏，不得挤压核心任务区。
- `accepted / needs_review / blocked` 继续作为内部质量状态；用户界面分别使用“可以导出 / 需要核对 / 必须修正”等任务语言。

## 三、视觉系统

### 3.1 色彩

| 角色 | 基准 | 用途 |
| :--- | :--- | :--- |
| 墨绿 | `#17694e` | 主操作、可信完成、品牌识别 |
| 深绿 | `#11251d` | 左侧栏和高层级背景 |
| 暖白 | `#faf9f3` | 内容纸张和核对区域 |
| 琥珀 | `#b06f16` | 需要核对、低置信提示 |
| 砖红 | `#a33b32` | 必须修正、失败和危险操作 |
| 灰绿 | `#647068` | 次要说明和辅助状态 |

状态不能只靠颜色表达，必须同时显示文字、边界或图形差异。禁止使用紫色渐变作为默认品牌背景，禁止用发光效果表达可点击或可信。

### 3.2 字体与层级

- 正文和控件优先使用 Windows 可用的中文界面字体，保证离线和跨机器稳定。
- 页面标题可使用宋体类衬线字体形成编辑感；阿谷品牌语可使用楷体，但不得进入数据表格和错误说明。
- 主标题约 22–25px，区域标题 14–17px，正文 11–13px，辅助信息不低于 10px。
- 不使用占据大面积空间的展示型标题，不用全大写英文替代中文任务名称。

### 3.3 间距、圆角与层级

- 默认使用 4px 基础节奏，常用间距为 8、12、16、20、24px。
- 控件圆角 10–12px，卡片圆角 14–18px；同一信息层级内保持一致。
- 阴影只用于区分纸张层级和浮动核对工具，不用于制造悬浮发光。
- 避免在卡片内部继续堆叠多个同等强调的卡片；需要分组时优先使用标题、分隔线和留白。

## 四、窗口与响应规则

- 默认窗口为 1280×820，支持的最小窗口为 1080×720。
- 宽度不超过 1180px 时缩窄侧栏、压缩水平间距和非关键统计。
- 高度不超过 760px 时启用紧凑高度：压缩侧栏、顶部状态区、处理状态和文件带，隐藏“最近操作”。
- 最小窗口下侧栏底部、隐私说明、核心按钮和状态必须完整可见。
- 应用外壳不滚动；表格、PDF、周视图和问题列表在各自内容区滚动，并保留当前页码、缩放和滚动位置。

## 五、组件规则

- 主按钮每个阶段只保留一个明确动作；危险操作使用砖红并写明后果。
- 文件标签显示课表类别、文件名和移除入口；无效文件同时显示原因，不能只变色。
- 结果状态封签显示“是否可用”和下一步，不展示内部引擎字段。
- 标签切换保留内容生命周期，避免销毁 PDF 与课程周视图。
- 表格强调可扫描性，表头固定，数字使用等宽数字，悬停只做轻微背景变化。
- 阿谷不得出现在 `blocked`、严肃证据区、问题卡片或审计表格中。

## 六、动效与反馈

- 按压反馈约 90ms，悬停约 140ms，内容进入约 220ms，面板切换约 300ms。
- 动效服务于状态变化、空间关系和操作确认，不使用持续漂浮、回弹、视差、3D 翻转或滚动驱动动画。
- 处理中允许循环进度；可信完成动画只播放一次；状态区高频更新按动画帧合并。
- `prefers-reduced-motion` 下停用非必要动画，`prefers-reduced-transparency` 下使用实色纸张，`prefers-contrast` 下提高边界和文字对比度。

## 七、离线与隐私边界

- 字体、图标、角色和背景全部来自系统或安装包，不引用运行时在线资源。
- 真实姓名、完整路径、课程正文和课表缩略图不得进入公开日志、示例和设计文档。
- 不以遥测、在线字体、云端识别或运行时素材下载换取视觉效果。

## 八、验收清单

- 1280×820 与 1080×720 下无外壳裁切，核心操作均可见。
- 欢迎、处理中、可以导出、需要核对、必须修正和失败状态均有明确下一步。
- 键盘焦点可见，颜色不是唯一状态信号。
- 减少动态、减少透明和高对比度模式可用。
- PDF 与课程周视图切换后保留页码、缩放、滚动和当前周。
- 未新增在线依赖，断网时界面和内置资源仍能使用。
