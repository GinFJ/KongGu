## 通用修复

- 英方星期与日期被分页切开时，结合相邻页明确印出的日期、星期、横向位置及相邻日历锚点连接证据；证据缺失或冲突保留复核，禁止猜日期。继承节次列不再错误裁掉续页顶部课程。
- 对宽合并格中低置信、疑似日历说明的 OCR，按 PDF 原始分辨率局部重读两次；只有边线、内容与两次识别一致才排除告示占用。保留原 OCR、来源哈希及局部证据；不一致时保留原结果和复核状态。
- 中方整学期表以实际周次栏边线结束位置区分课表与表底说明，不按固定周数截断，不把较矮的课程说明区当成额外教学周。

没有加入真实姓名、文件哈希或某一周的识别特判，没有增加运行依赖或在线服务。全新输入继续按自身内容识别；历史确认与修正仍受来源和解析签名约束。

- 单独合成材料完成修改节次、重算、导出和人工修正历史检查，不把合成材料算作真实原件覆盖。
