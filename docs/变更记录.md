## 2026-08-14 · 0.5.2 安全与隐私加固

### 类型

安全与隐私修复（patch）：修复 Excel 公式注入、过度持久化、Tauri 权限、PDF 资源耗尽、离线资源路径穿越、错误路径泄露和 Python 依赖漂移风险。

### 变更内容

- Excel 所有写入边界统一转义公式样式字符串，避免成员、课程、文件名、问题和修正文本被当成公式。
- 任务请求和结果快照不再保存文件绝对路径；任务进入完成、失败或取消终态后立即清除数据库路径；待复核任务仅在当前 sidecar 会话保留原文核对路径。

- 配置生产 CSP，移除 `fs:default`、shell execute 和任意 sidecar 参数，增加前端命令 allowlist。
- 增加 PDF 单文件、批量文件、总大小、总页数、加密和解析核心二次门禁；manifest source/target 强制 containment。
- sidecar 不再返回 traceback，错误和资源状态统一脱敏；锁定 Python 依赖版本。

### 验证结果

- Python 全量测试：`154 passed, 2 warnings`；使用 `.venv\Scripts\python.exe -m pytest -q --basetemp tmp\pytest-security`。

- Python 编译检查：`compileall -q app core tools` 通过。
- 静态安全检查：未发现明显密钥；CSP 已配置，`fs:default` 和 `shell:allow-execute` 已移除。
- 尚未重新构建 0.5.2 安装包，也未完成真实安装、断网、多账户 ACL、卸载和恶意 PDF 模糊测试。
