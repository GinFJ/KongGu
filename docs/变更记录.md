## 2026-08-11 · 阿谷虚拟形象与 0.4.2

### 类型

品牌与体验补丁（patch）：建立空谷虚拟形象及确定性资产链，将角色用于启动、欢迎和可信完成场景，不改变课表解析、质量门禁或导出数据契约。

### 变更内容

- 确立空谷非人虚拟形象“阿谷”：以双叶冠、透明青心种仁和圆润谷粒身体作为不可替换的三项识别特征，统一“青心如禾，向阳而生”的角色表达。
- 新增标准母版、动态立绘、课表主题立绘、完成立绘、头像、应用图标、启动场景和宣传卡；`assets/brand/agu/manifest.json` 记录尺寸与 SHA-256。
- 新增 `tools/build_agu_assets.py`，从四张确认源图确定性重建 WebP、头像、图标、启动场景、宣传卡和 Tauri 图标，避免手工只修单个产物。
- 桌面端接入阿谷启动页、未导入欢迎页和通过质量门禁后的完成状态；`blocked`、严肃复核区和审计表格不使用角色主视觉。
- 新增 `docs/品牌/阿谷角色与视觉使用规范.md`，并在 README 与参考资料登记表中建立入口；窗口标题统一为“空谷 Konggu”。
- 修正普通浏览器预览时暴露底层 `transformCallback` 文案的问题，改为可行动的桌面端提示。
- 源码版本标识由 0.4.1 升至 0.4.2。

- 前端构建：通过（Vite 8.1.3，43 modules，635ms）；主 JS 748.74 kB（gzip 221.14 kB），保留既有 chunk 体积提示。

- 本地浏览器视觉检查：默认窗口与 1080×820 最小窗口下，欢迎页无裁切或遮挡；普通浏览器错误提示已转为桌面端使用指引。

## 2026-08-09 · PDF Inspector 旁路诊断与 0.4.0

### 类型

新增功能（minor）：PDF 结构诊断、逐页 OCR 建议和复核页解释，不改变正式课程块与质量门禁。

### 变更内容

- 研究并固定 Firecrawl Python binding `pdf-inspector==0.2.6`；新增 `core/pdf_inspection.py` 适配层，统一输出空谷自有诊断契约和 1-based 页码。
- 解析前本地检查文本型、扫描型、图片型和混合型 PDF，记录逐页 OCR 原因、编码异常、表格/多栏提示与引擎版本；失败时回退 PyMuPDF。
- 设置单文件 50 MB、100 页的结构检查上限；诊断结果不保存课表正文，不直接改变 `accepted / needs_review / blocked`。
- 诊断结果进入工作流快照、文件处理表和 PDF 复核侧栏；切换来源时只显示对应文件的课程框和诊断信息。
- 新增 sidecar `pdf.inspect` 命令、单元测试和 GitHub 原始资料研究笔记。
- PyInstaller 显式收集原生扩展、包元数据、SBOM 与 MIT 许可证；源码版本由 0.3.2 升至 0.4.0。

### 验证结果

- Python 全量测试：`97 passed, 2 warnings`（2026-08-09，Python 3.12.4，pytest 9.1.1）。
- 前端构建：通过（Vite 8.1.3，40 modules，487ms）；主 JS 747.34 kB，保留既有 chunk 体积提示。
- 桌面层检查：`cargo check --manifest-path src-tauri\Cargo.toml --locked` 通过（konggu v0.4.0，17.93s）。
- sidecar 冻结：通过；`konggu-worker.exe` 278,139,040 字节，SHA-256 `9D1E28E4BF77F4FCC1539A4B76766D7F4E40EF56BC219872DF8B91D6937B141F`。
- 冻结冒烟：`pdf.inspect` 在合成文本 PDF 上返回 `firecrawl_pdf_inspector 0.2.6 / text_based / 1 页 / 无 OCR 页`。
- 冻结归档：包含 `pdf_inspector.pyd` 和 MIT LICENSE，不包含本地 `direct_url.json`。
- 仓库外真实样本旁路检查：70 份、109 页全部完成；53 份文本型、16 份图片型、1 份扫描型；建议 OCR 26 页，与 PyMuPDF 的 26 个无文本层页面完全一致。

### 证据状态与限制

- 源码功能已提交为 `e7ab4ef` 并同步至 `kongguV0.1`；未建立新标签、未发布。
- 真实样本对账只验证页级文本层判断，不构成课程块准确率证据；逐页 OCR 路由、完整安装包、断网和全新用户目录仍未验证。
- 首次 pytest 因系统临时目录权限报 `WinError 5`，改用项目内独立 `--basetemp` 后全量通过；功能断言没有失败。
