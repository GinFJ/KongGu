# AI 原页核对使用说明（0.9.0）

日期：2026-11-16。私有安装候选已构建并通过本版列明的本地验证，具体范围见[本版验收](交付验收_0.9.0_v1.0.md)。

## 使用方法

1. 按原流程导入、解析中英方课表，在“核对问题 → 原文核对”选择原件和页码。
2. 点击“AI 核对当前页”。此时只在本机生成发送预览，不联网。
3. 检查预览。程序会遮盖能够定位的文本层姓名；图片中的姓名、学号等需要拖动鼠标画白色遮盖框。保留日期、星期、节次表头和必要图例。清除手动遮盖不会恢复已自动遮盖的姓名。
4. 选择模型，勾选本次发送同意项，再发送这一页。传输内容是遮盖后的图片、课表类别和本批校历，不发送原 PDF、文件名、目录或成员名单。
5. 查看“疑似漏课”“依据不足”“校外课程”和“本地有而 AI 未确认”的占用。模型一致不能代替人工核验，AI 未读到也不能直接证明没有课。
6. 疑似漏课需对照原文、填写核对说明，再逐条补录。仅补录本地尚无占用的节次；日期、星期与校历矛盾或证据不足的建议不能一键采用。
7. AI 差异会增加待复核问题，处理后回到原文核对中确认。缺页、身份冲突、截断和未覆盖日期的既有阻断继续有效。补录后自动重算，记录 AI 观察编号、模型、提示版本、原页依据和人工说明，可按既有修正入口撤销。

## 网络、费用与范围

- 默认仍为本地处理；联网功能通过 Python worker 直连 `https://api.openai.com/v1/responses`，无需部署后台。没有新增运行依赖，也没有云端工具调用或模型下载。
- 本版可以按提供者明确授权，在私有安装候选中携带共享 API 密钥，费用记入提供者的账户。共享密钥可被提取，封装不是保密措施；本机限制无法约束安装包之外的调用，不应把它宣传为安全的统一计费服务。
- 默认候选模型为 `gpt-6.1-sol`，也可选择 `gpt-4.1`、`gpt-4o`。账户模型权限、额度及所在地服务支持范围决定实际可用性；失败时不自动换模型或重试。
- 每次一页、最多 12000 个输出 token，本机每日最多 50 次尝试（UTC 日期）。缓存命中不联网；不同模型、遮盖内容、提示版本、源哈希或解析/校历签名不共用观察。响应超时 180 秒，超时或断开不代表供应商必然未计费。
- 结果界面显示 API 返回的输入/输出 token，不把它当成精确账单。API 默认不用于训练不代表零留存；`store=false` 不排除安全监测及模型缓存等留存。
- 图像预览最多保留 8 页、15 分钟内可用于发送；打开新预览时清理过期项，清理本机记录或退出程序也会清掉预览。AI 观察保存在本机任务数据库，随任务删除级联清除；再次使用相关 AI 数据操作时清理超过 30 天的观察及约 32 天前的调用统计。调用统计只记录请求编号、UTC 日期和 token；程序未运行时不会定时清理磁盘记录。
- 相同原件再次导入时，仍有差异的既有 AI 观察会重新产生复核提示，不能靠重导入绕过。曾经的人工确认不直接当作新任务的 AI 核验。

## 已知限制

这是逐页 AI 辅助复核，不是全文件无人值守识别。必须先有可复核的本地解析任务；全部原件均解析失败的批次不能靠本入口直接恢复。跨页、密集大表、图例在其他页和未明确年份仍可能需要人工处理。当前仅支持核准后的漏课补录，误占用删除和时间修改沿用原文核对入口；不自动替换全部课程。

真实课表准确率、完整学期独立真值和其他用户电脑网络可用性必须另行测量。合成 API 连通成功不代表这些项目已经通过。

## 私有构建

普通构建不携带凭据；没有另外配置运行环境密钥时，AI 入口会显示未配置。私有构建可使用 `KONGGU_AI_CREDENTIAL_FILE` 指定版本库外或已忽略目录中的 `ai-credential.json`，其唯一必需字段为 `api_key`。打包工具将此文件加入 worker 的 `private/` 资源，源文件、前端、公开文档和日志不包含密钥。该变量不是运行时上传开关。运行进程若另设 `OPENAI_API_KEY`，它优先于包内凭据，费用由该密钥所属账户承担。

已分发包的密钥更新需要重新构建或撤销旧密钥；共享密钥撤销会让旧包的 AI 功能停止，离线功能仍可使用。不得把私有候选上传公开仓库或公开 Release。
