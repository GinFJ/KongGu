# Windows 跨电脑兼容性验收补充

日期：2026-11-16。针对既有 0.9.0 Windows x64 私有候选；本轮只补充兼容性验收工具 1.0 与证据，未修改应用运行代码、依赖、版本或安装器。原安装器 SHA-256 为 `8fd572abfdf9f7eb89dd8c270017dc0c1e6ffe069f9928b1d694268455d1ff72`。本记录不是其他电脑已经通过的结论。

用户确认暂时没有 Mac，本轮只做 Windows；用户愿意在另一台 Windows 电脑上运行安装包与自检工具。Mac 支持保留为后续事项，当前 `.exe` 不作为 macOS 安装包。

## 本机已执行的检查

自检使用 Windows 自带 PowerShell 5.1 / .NET，不要求目标电脑安装 Python、Node、Rust、Office 或开发工具。驱动代码见 `tools/windows_compatibility/windows-selfcheck.ps1`，输入仅是随工具提供的 3 份合成 PDF；图片 PDF 为故意需要复核的负例，不包含真实个人课表。

| 检查 | 实际行为与证据 |
|---|---|
| 候选与安装态 | 注册表当前为 0.9.0；安装目录主程序、worker 哈希与最终候选匹配。本轮没有运行安装器，不能倒推安装/升级/卸载全流程已验收 |
| 开发环境隔离 | 子进程只继承 Windows 系统 PATH，清除 Python、模型缓存、业务数据及 API 环境变量；从包内恢复资源 |
| 普通权限与中文路径 | 本机以非管理员权限，在中文及空格安装路径、用户路径、临时路径下运行实际冻结 worker |
| 无写入权限 | 仅在自检目录内创建真实拒绝写入 ACL，验证安装目录不必可写；ProgramData 不可写时，模型回退到可写英文 Public 路径。结束后恢复自检目录 ACL |
| 业务链路 | 合成文本课表解析、预览、删除恢复、重算、Excel 结构检查；实际图片 OCR 读出标记；未复核/阻断结果禁止导出 |
| AI 配置 | 凭据可加载，合成原页预览可生成；本次自检不发送 API 请求，不验证对方电脑的联网条件 |
| 重启与文件保持 | 正常退出后重新启动，任务和修正记录仍可读取；worker 字节哈希未变化 |

解包 worker 的首轮完整检查通过，用时 78.93 秒；随后用最终工具、默认安装路径对当前已安装的 worker 完整复验通过，用时 77.83 秒。两次均为当前 Windows 11 25H2 / build 26200、同一个 Windows 账户；中文 profile 为独立模拟目录，不是真实第二账户或另一台电脑。

工具将 HTTP/HTTPS 代理指向不可用的本机端口，并设置模型离线开关。它证明这个受控条件下的本地处理流程可运行，不等同于网卡断开、防火墙全量封锁或全新 Windows 虚拟机。当前电脑没有可用的 Windows Sandbox 或现成干净虚拟机，本轮没有安装或启用虚拟化功能。

## 另一台电脑的验收步骤

1. 使用 Windows 10/11 的 x64 电脑，完整解压验证包。当前不把 32 位 Windows、Windows ARM64、macOS 列入已验证支持范围。自检目录所在磁盘至少保留 2 GiB 空间；安装器还需要自身安装空间。
2. 关闭空谷。可在断网状态下安装 `Konggu_0.9.0_x64-setup.exe`，记录是否需要联网补依赖、是否正常完成；安装器需要正常管理员确认。
3. 安装完成后，普通双击 `一键自检.cmd`，不要以管理员身份运行。工具会创建独立测试目录，不读取或清理已有空谷业务数据。运行完会在工具目录生成带时间戳的 `自检结果-*.json`、`自检结果-*.txt`；目录不可写时显示 Public 下的实际位置。
4. 打开空谷窗口，学期第一周设为 `2026-03-02`、教学周数 `18`，导入 `samples` 顶层的两份合成 PDF，生成、查看并导出。`samples/image` 是负例，单独导入检查复核阻断，不与同名英方文件一起导入。
5. 重新联网，在合成课表的“原文核对”中测试一次 AI 发送。确认能正常返回结果；此项会使用提供者的 API 额度。自检 JSON 中的 `api_request_sent=false` 不表示人工 AI 测试失败，只表示自动工具未发送。
6. 退出重开，确认任务仍在；在测试机允许的情况下卸载后重装，检查卸载和数据保留。记录这些人工操作结果。已有重要业务数据时，先自行备份再做卸载测试。

发回两个自检报告，并说明安装、窗口操作、断网、AI 发送及卸载重装各自是否成功。不要发送整个自检数据目录；其中的模型、可执行文件和图片没有排查报告所需的信息。

## 判断边界与后续

当前结果是“本机兼容性加强检查通过，另一台机器待用户实测”。不能承诺所有 Windows 硬件、旧系统、企业策略和网络都无问题。Windows 10 与其他 CPU 的实际 OCR/动态库兼容性、不同 WebView2 环境、另一账户权限、杀毒拦截和 API 网络条件，以对方报告和原生窗口实测为准。

工具只接受对应 worker 哈希，避免旧版本误报通过；缺少程序、权限过高、非目标架构、磁盘不足或协议/业务失败时返回非零退出码，并保留失败报告。结果只包含版本、OS build、架构、耗时、哈希与检查结果，不采集用户名、电脑名或真实课表。

既有产品、隐私、回滚及其他验收证据见[0.9.0 交付验收](交付验收_0.9.0_v1.0.md)与[AI 使用说明](AI识别使用说明_0.9.0.md)。私有安装包含已授权共享凭据，验证包沿用相同私人分发边界，不上传公开仓库或 Release。
