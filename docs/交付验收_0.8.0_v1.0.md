## 本版功能

在原文核对中补录漏课、删除误识别记录、恢复已删记录、恢复自动误排除区域或排除已核实的非课程区域。每次填写原因后，课程、成员占用、空闲预览和导出共同重算；操作前后、原因、操作者及时间写入事务记录。可撤销本原件最近一次课程操作，撤销也留痕。原 PDF 不变。

记录绑定原件哈希、文件名、成员身份、日历/解析签名和前置课程状态；恢复区域另校验原图区域证据。重新导入只复用完全匹配的操作，依据改变时保留复核，不静默套用旧结果。请求重复不会增加两条记录，旧界面状态不能覆盖新结果，保存失败整笔回滚。删除最后一条课程仍保留成员及已提交来源，不把零课程误判为缺交。

多节补录在课程明细中按节次展开，各自对应实际时间。课程周视图按钟点排列午间和下午，不连续节次分段显示；分段记录在原文核对修改，防止拖动一段丢失其他节次。缺页、身份冲突、截断和未覆盖日期不因修改课程解除。没有新增依赖、在线识别或运行时模型下载。用户操作见[使用说明](人工修正使用说明_0.8.0.md)。
