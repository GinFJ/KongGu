# 现有材料下的复用性验证

本流程检查解析规则是否依赖成员、OCR项顺序、页面位置、尺寸和分页顺序。它不能把已经参与调试的材料变成独立未见样本，也不能用占用一致性替代课程名称准确率。

## 固定验收条件

1. 先冻结代码哈希、源文件哈希、真值版本和统一变换参数，保留失败结果；后续修改只能记录为修复后回归。
2. 同一PDF只更换测试文件名、打乱OCR项顺序、缩放至80%/125%、四边增加20%页面尺寸的留白，或倒序排列完整页面。日期、课程和节次语义不变，预期整学期占用集合不变。
3. 将像素与原始OCR坐标同步变换，只能验证解析层。必须另外使用空缓存重新OCR，检查OCR变化与解析变化，不能混报。
4. 删除原页中的一个课程格，同时移除该格对应的OCR项，预期仅减少该课程格的占用。该反向对照检查程序是否响应内容变化，不能当作独立人工真值。
5. 保留原件和人工表，人工真值只用于结果比较，不能作为解析输入；已参与调试的样本不得重新命名为盲测集。

## 可重复运行

`tools/audit_layout_invariance.py` 读取版本库外的清单，调用生产解析函数，不读取人工空课答案，不新增模型、依赖或联网处理。输出含推导OCR文本的缓存，必须保存在版本库外。

清单示意（路径替换为本机已授权材料）：

```json
{
  "semester_start": "2026-08-31",
  "teaching_weeks": 20,
  "records": [
    {"pdf": "D:/样本审计/原件.pdf", "ocr_layout": "D:/样本审计/坐标.json", "kind": "中方"}
  ]
}
```

运行：

```powershell
.\.venv\Scripts\python.exe tools\audit_layout_invariance.py --manifest D:\样本审计\manifest.private.json --output D:\样本审计\复用检查
```

报告只输出匿名来源编号和差异数量。源文件与缓存哈希不符时拒绝执行；占用发生变化、原始结果为空或运行中源码发生变化时，报告为`blocked`并返回退出码1。这是复用验收不通过，不是准确率结论，也不是应用内课程来源的质量状态。

## 使用边界

规则支持某一种课表版式，不等于支持任意表格。每个版式应分别记录原件覆盖、内容改变对照、排版变体、冷OCR与人工真值的证据。检查不通过时，应修复通用几何或结构规则，或明确保留复核状态，不增加按真实姓名、文件哈希、指定周次返回答案的分支。

当前中方、英方含图片页的来源均需核对后才能正式导出；`OCR成功`及`原件目标周对照一致`都不能自动解除其他周次或新版式的复核要求。

最近算法证据见[0.5.29验收记录](迭代验收_0.5.29_v1.0.txt)：同条件127项解析变体均通过；冷OCR、未见版式和全学期真值仍未完成。下方0.5.24—0.5.28记录属于各版历史过程，不能把其未通过计数当成当前结果。源码0.5.30只整理文档，解析签名仍为65，未重新运行本流程。完整私有证据保存在版本库外审计区，交付与遗留见[当前待办](../MEMORY/待办.md)。

## 分页变量必须单独控制

原127项工具中的`reverse_pages`通过`show_pdf_page`重新封装页面并同步变换OCR坐标，既改变顺序，也可能改变抗锯齿和像素取样。它应被描述为“倒序并重新封装”的组合压力检查，不能单独证明页序是根因。保留这组旧条件便于版本比较，不以更换测试消除失败。

另设纯页序对照：使用`insert_pdf`倒序复制完整页面，只修改OCR项的页码，不缩放坐标；逐页比较120 DPI渲染像素，确认与原对应页完全相同，再比较解析占用。该检查仍属于使用原始OCR坐标的解析层验证。

0.5.25将跨页回退表头改为按可见边界、标签完整度及稳定坐标规则统一选择，不随前一页变化；纯页序对照15份均一致。更换版式或页面尺寸时仍须单独验证，不能据此保证表头可以任意跨版式借用。

模板还必须满足节次中心从左到右递增；标签看似齐全但坐标交叉、重叠或逆序的候选必须被排除。统一选择保证确定性，几何校验和原件真值对照才能进一步约束正确性，两者不能互相替代。

## 本轮规则改进的边界

0.5.25按持续的竖向线段判断合并格，线段长度随观测行高调整；只允许共享实际边界的节次格推断合并，避免跨过空白间隔列。时间表头区域与课程行按可见横线区分，识别失败的表头文字也不能落入课程。页首/页尾未封闭的续行保留可见部分，不因此关闭其他完整行的边界校验。

这些是版式结构规则，不是新OCR模型，也不包含按成员或目标周返回课程的补丁。中方小字/非课程标记的像素稳定性、冷OCR结果差异和其他周次真值仍需继续验证。

## 0.5.26 的尺度与局部边界约束

中方小格补偿只允许降低缩小格子的固定裁边和最小墨量，大行维持原阈值，避免将增加行高当成放大字号。识别到近等高的正文行时，两种视觉解析路径都使用完整正文边界的平均原始行高，减少单行29/30像素取整波动；非均匀行回退按格判断。占用面积比仍可能处于临界值，不能由此宣称任意缩放或平移都稳定。

英方表头竖线提取以实际表格行距确定长度，不随整页留白变长。合并判断检查当前行的边界邻域，主解析和补充阶段统一使用有效首表头及补齐后的日期。共享边界与空白间隔列约束继续保留。

对灰色填充课程格，竖线检测改用局部亮背景与原图的对比，保留真实深色边缘，再提取连续长竖线；不会把整块均匀灰色底色当成线。使用局部亮包络而非闭运算估计背景，以免粗于窗口的真实竖线被消除。测试同时覆盖灰底、真实分隔、合并格、短字形笔画与粗线。

冷OCR比较中的参考文字也可能识错，例如把“校外”地点首字读错。现有业务规则规定“校外”开头地点不计占用，不能为了减少两次解析差异而恢复这些课程占用；冷OCR结果应继续对照原页及业务规则，不能把推导坐标结果直接当完整真值。

组合变体需逐项比较改善和退步，不只比较通过总数。具体计数、未通过项及本轮是否重新OCR，以0.5.26变更记录和版本库外冻结报告为准。

## 0.5.27 的规范标记与列距约束

元旦/元旦节、中秋节、国庆节及独立研究生考试告示采用精确类别匹配；四六级事件使用受约束的整串结构，并保留培训、辅导、课程等真实标题。实际整学期文本解析和基础分类保持同一口径，不使用旧的四六级子串再次误删课程。

中方合并告示以连续物理竖线界定区域，排除字形笔画造成的伪边界。英方正常节次距使用中位数，避免一个读窄的列影响其他正常合并；实际共享边界与空白间隔保护保持不变。

当前同条件组合变体为126/127，一项“教研”字形的OCR异读仍需复核。单页字形共识是研究证据，未用该异读词做专用排除；126/127不能解释为识别准确率，冷OCR和非目标周独立真值仍是分开的验证层。

## 0.5.28 同页字形建议的证据边界

同页原OCR中规范“教研/不排课”可以作为参照；至少两个物理独立、同页同类区域通过几何、覆盖和拓扑约束后，只生成建议。课程码（含全角）、长标题、额外中文内容、跨边界框、重复框歧义和冲突规范标签均拒绝。原OCR不改写，候选不能成为后续种子。

当前建议保留原占用，并独立进入复核与导出门禁。证据含原文、页面/周次/节次、区域及参照分数，绑定源哈希与解析/OCR签名，随缓存、内存、快照及review保留。确认只记录核对，不应用删除；界面尚无该类占用删除入口，确为非课程时保留待复核并修复重解析。

自动排除中间方案产生新变体退步，固定矢量内容区域渲染也未稳定，因此均未采用；不是为凑满127而扩充别字词表。最终仍126/127，S24缩小差异保留，全部已解析原件占用与0.5.27相同。工具冻结列表现在包含独立字形模块，运行时源码变化不得计为通过。最终签名63使试验62结果失效。

本轮未更换或训练OCR模型、未新跑OCR，没有新增未见来源。具体491项测试、740项目标周对照、控制条件和未完成事项见0.5.28变更记录及验收记录；这些计数不代表准确率。

## 0.5.29 原PDF字形裁取的支持边界

本轮在文字已转曲、且能证明场景无干扰的纯矢量页上提取完整字形区域，统一尺寸后与同页两处原OCR严格规范标记比对。输入身份确认和校历设置沿用已有记录；算法不按姓名、指定源哈希或目标周次适配，原件与真值v1.1均未改。

get_drawings仅用于区域及场景分析；它会遗漏部分移动子路径信息，不能据其重建原图。最终使用原页面DisplayList裁取，保留真实填充，并在单次页内匹配中复用；混合文字/图像、注释、未知图形状态、遮盖及不明裁切采用保守回退。像素框完整性与矢量实际完整路径分开检验，矢量内容区域使用未取整坐标，避免表格边线舍入侵入。

强判断只对待复核预览排除，弱像素建议不改变占用；专项未确认仍禁止正式导出。小型独立附加轮廓和课程码等反例可拒绝，但附着细笔画仍可能高分误配；覆盖率不是语义准确率。源码中的真实内存PDF边界回归验证了此时仍有专项门禁，没有发现未核对即可正式导出的绕过。

最终解析层同条件127/127通过；原件目标周740/740，Python558通过；额外中方9项、原附加3项、纯页序15项、图像擦除7项均一致。5组新增12个教研判断有原页AI字形依据，共移除48项非目标周中方来源占用；这些不是独立人工全年真值，仍未放行。未新跑OCR，未新增未见材料，未构建安装包；总体识别准确率与未见版式泛化尚未验证。具体证据与限制见0.5.29变更记录及验收记录。
