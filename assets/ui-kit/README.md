# Konggu UI Asset Kit

Generated raster assets for Konggu's README and product UI.

## Theme

- Soft ivory base
- Mint, teal, sky blue, and pale yellow accents
- Translucent timetable grids
- Availability path lines
- PDF, OCR, calendar, member-check, and Excel export motifs
- Fresh sprout visual as the core metaphor

## Assets

| File | Suggested use |
| --- | --- |
| `header-background.png` | App header, landing area, README section banner |
| `empty-upload.png` | Empty upload state or onboarding panel |
| `feature-icon-sheet.png` | Feature icons, README graphic, or sliced UI tiles |
| `workflow-cards.png` | Workflow / process section visual |
| `panel-texture.png` | Sidebar, card, or subtle panel background |

## Notes

These images were generated with ChatGPT image generation. They intentionally avoid readable text so they can be used in both Chinese and English UI contexts.
