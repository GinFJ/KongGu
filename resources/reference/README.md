# resources/reference 参考库说明

本目录用于保存完成空谷项目工作所需的参考材料，不保存当前代码、正式构建产物或动态项目状态。

> 说明：仓库顶层 `resources/` 同时承载运行时离线资源（OCR 模型与 `offline_manifest.json`）。参考材料固定放在本子目录 `resources/reference/`，两者不混放。

## 可以存放

- 产品和视觉模板；
- 脱敏课表样例；
- 课表版式说明；
- 人工标注规范；
- Excel、Word、PDF 交付模板；
- 历史设计稿和参考截图；
- 外部技术资料；
- OCR、PDF 解析和桌面端实现参考；
- 用户反馈的脱敏摘要。

## 不应存放

- 真实姓名和原始课表；
- 含个人信息的日志；
- 当前版本、分支和测试状态；
- 可直接运行的源代码；
- 构建目录、缓存和正式安装包；
- 未注明来源和时间点的性能数字。

## 文件命名建议

```text
类别_主题_来源_日期_状态.ext
```

示例：

```text
模板_空课汇总表_内部_2026-08-08_有效.xlsx
样例_英方周课表_脱敏_2026-08-08_已核验.pdf
参考_PDF文本提取_外部_2026-08-08_待评估.md
```

新增资料后，在 `资料登记表.md` 中登记来源、用途、隐私级别和有效状态。
