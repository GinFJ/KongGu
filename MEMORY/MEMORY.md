## 一、项目定位

空谷是青禾计划孵化的课表协作产品。“空”指空课表，“谷”承接青禾从禾苗生长为谷物的意象。

核心任务是汇总多人中方、英方课表，生成可信、可复核、可追溯、可导出的集体空闲结果，主要服务学生组织的值班、活动、会议、培训和志愿服务排班。

## 二、长期原则

- 离线 Windows 交付。
- 课表数据本地处理。
- 可信结果和完整责任链优先于功能数量。
- 文本层优先，本地 OCR 或视觉回退仅在必要时使用。
- 出现错误时修复解析器、预检、配置、质量规则或回归体系，不手工修补单个输出文件。
- 正式结果必须通过质量门禁。
