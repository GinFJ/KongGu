## 项目与范围

空谷是青禾计划孵化的课表协作产品。“空”指空课表，“谷”承接青禾从禾苗生长为谷物的意象。面向学生组织，汇总多人中方、英方课表，生成可核对、可追溯的集体空闲结果；坚持离线 Windows 与本地处理。
